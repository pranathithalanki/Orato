# Voice To-Do App: PRD

## Problem
I forget tasks and calls I need to make. Typing them into a to-do app is
slow, so I don't do it. I want to speak and have the app work out the tasks. 

## Users
- Me (college student)
- My brother (first tester, Android, speaks mostly English with some Hindi)

## v1 Features
- Basic to-do list (add, tick off, delete), saved on the phone
- Mic button that converts speech to text
- Splits the text into separate items
- Two categories: **Tasks** and **Calls** (a call has a person's name)
- Confirm screen: review extracted items, edit, then save
- Reminders for items with a date or time

## Out of scope for v1
- Auto-saving without confirmation
- Stocks tab (news and trends)
- Cloud sync and user accounts
- iPhone support
